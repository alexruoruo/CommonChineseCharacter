# 识字大冒险 · 汪汪队与奥特曼

一个纯静态、零依赖的 H5 网页小游戏,专为 5 岁以上小朋友设计:汪汪队狗狗出题、奥特曼陪打怪,边闯关边识字,手机竖屏优先适配。

> ⚠️ 版权提示:本游戏为**家庭自用**的学习小游戏,玩法包装中提到的「汪汪队 / PAW Patrol / 奥特曼 / 迪迦 / 赛罗」等名称仅作为文字引用,游戏内**不包含任何动画片图片、音频等素材**,角色一律用系统 emoji(🦸 🐕 🚒 ♻️ …)代替,请勿用于商业用途或公开分发。

## 怎么玩

- **直接双击打开 `index.html`** 即可(数据用 `<script>` 标签加载,`file://` 协议也能玩);
  也可以本地起个服务:`python -m http.server 8000` 后访问 `http://localhost:8000/game/`。
- 进度自动保存在浏览器 `localStorage`(键名 `hz-hero-v3`),换浏览器/清缓存会重置。

## 词库分年级

字库共 **3505 个汉字**,按 7 档分层,识字量对照《义务教育语文课程标准(2022 年版)》各学段目标,教材字表采用**统编版语文(2024 新教材,即深圳现用教材)**,已逐字核对国家中小学智慧教育平台电子课本:

| 年级 | 字数 | 累计 | 内容 |
| --- | --- | --- | --- |
| 一年级上册 | 280 | 280 | 统编 2024 版一上识字表,按课文顺序(天地人你我他…) |
| 一年级下册 | 409 | 689 | 统编版一下识字表(官方 410 个生字),按课文顺序 |
| 二年级 | 911 | 1600 | 二上识字表 + 按笔画补齐,达成第一学段累计识字 1600 |
| 三年级 | 450 | 2050 | 其余常用字按笔画由易到难 |
| 四年级 | 450 | 2500 | 达成第二学段累计识字 2500(≈常用字 2500) |
| 五六年级 | 500 | 3000 | 次常用字按笔画由易到难,达成第三学段累计识字 3000 |
| 课外拓展 | 505 | 3505 | 其余次常用字(进阶挑战) |

每关 5~8 个新字(低年级字少一点),先「学一学」再答题;每 10 关一章,**章末是 👾BOSS 关**;前一年级闯过 2 章即解锁下一个年级。

## 玩法说明

| 环节 | 出题狗狗 | 内容 |
| --- | --- | --- |
| 🔊 听一听 | 🚒 毛毛 | 听读音选字(无 TTS 时自动降级为看字选音) |
| 📖 读一读 | ♻️ 灰灰 | 看字选正确读音,干扰项同声母 |
| 🎵 看拼音 | 🐕 阿奇 | 根据拼音从 4 个同声母字里选字 |
| 🔍 找一找 | 🏗️ 小砾 | 从 6 个形近字里找出与目标相同的字 |
| 👀 火眼金睛 | 🚁 天天 | 12 个字里找出不一样的那个 |
| 🚤 复习巡逻 | 🚤 路马 | 每关最后 2 题智能复习旧字(见下) |

- 3 颗爱心开局,答错扣 1 颗;**连续答错 2 次会高亮正确答案**,永不失败,答完按剩余爱心评 1~3 星。
- **⚡ 能量条**:一次答对 +16、答对但错过 +8、连击 ≥5 再 +4;攒满 100 释放**奥特曼必杀技**(全屏光束,恢复 1 颗爱心)。
- **🔥 连击**:连续答对有连击提示,鼓励孩子专注不乱点。
- **🦴 骨头**:通关奖励(三星 2 根、其他 1 根、BOSS 关 +2),集在小钱包里。
- **🦸 奥特曼伙伴**:打败章末 BOSS 掉落一张伙伴卡(迪迦、赛罗、泰罗……共 16 位),在「伙伴图鉴」里收集;集齐后 BOSS 改为多给 5 根骨头。点卡片有意想不到的台词 😄

## 怎么判断"真认识"而不是猜对?

选择题蒙也能蒙对,所以游戏给每个字建了**识字档案**(存在浏览器里):见过、一次答对次数、强题型答对次数、答错次数、连续答对链。判定规则:

- **只有"一次答对"才算证据**:本题答错过的、看提示后选对的、错题马上重问的,统统不计入;
- **听一听 / 读一读是强题型**:必须真知道这个字的读音,没法靠"长得像"排除法蒙;找一找、火眼金睛只考察认形;
- **认识的标准**:连续 2 次"一次答对",且其中至少 1 次来自强题型 → 标记 ✅ 认识了;
- **答错的字马上重问一次**(本关末尾,不计证据),并进入"要多练练"名单;
- **复习题智能选字**:每关最后 2 题优先挑「快认识了」和「错过的」**更早关卡学过的字**,帮助把字真正记牢。

首页点「📖 识字本」可以看到三本名单:**✅ 认识了 / 🌱 学习中 / 🔁 要多练练**,可按年级筛选,点字卡即朗读;结算页的字卡带 ✓ 角标的也是已认识的字。

```
game/

└── README.md       本文件
```

## 重新生成字库数据

修改了仓库里的 txt 词库后,重跑生成脚本即可(需要 Python 3 和 `pypinyin`):

```bash
pip install pypinyin
python tools/build-data.py
```

脚本会读取仓库根目录的 `3500常用字.txt`(取字)和 `7000常用字.txt`(取笔画数,注意:必须是带「N画」标记的版本,不是优化版),重新生成 `js/data.js`。三个教材识字表是脚本里的 `G1A`(一上 280 字)/ `G1X`(一下)/ `WS2S`(二上)常量,已按统编版课本顺序逐字核对;想换教材直接改那几个字符串即可。各学段累计识字量由 `CUM_TARGETS` 控制(默认 1600/2500/3000,对照 2022 课标)。

## 自定义难度

都在 `js/app.js` 顶部的配置区:

| 常量 | 默认 | 说明 |
| --- | --- | --- |
| `LEVEL_SIZE` | {1:5, 2:6, …, 7:8} | 每个年级每关新字个数 |
| `CHAPTER_SIZE` | 10 | 每章关卡数(章末即 BOSS) |
| `HEROES` | 16 位 | 奥特曼伙伴名单,按收集顺序 |
| `BOSSES` | 8 只 | BOSS 怪物(循环使用),可自行增删 |
| `PUPS` / `PUP_INFO` | 6 只 | 汪汪队狗狗与各自题型、台词 |
